# Rebrand: from "Sudoku" to "Sudoclue"

## Context

The app is called "Sudoku" today and is heading to the iPhone App Store through Capacitor. Its pitch is teaching: hints that explain the next deduction, a Learn page with 14 techniques, and guided walkthroughs. Sean is considering renaming it "Sudoku Sensei". This spike checks whether the name is free on the stores, in trademarks, and on domains and handles, lists alternatives, and maps what a rename touches in this repo. All checks were run on 2026-10-09.

## Key findings

- **The exact positioning is taken, and very recently.** "Sudoku Sensei: Learn & Master" by Abdelrahman Ashraf went live on the US App Store on 2026-09-29 (version 1.1, updated 2026-10-07). Its description is close to ours: a hint that names the technique, a "Why?" button with the reasoning, one-line mistake explanations, and ten techniques. Source: [App Store listing](https://apps.apple.com/us/app/sudoku-sensei-learn-master/id6816779631), metadata via the [iTunes lookup API](https://itunes.apple.com/lookup?id=6816779631&country=us).
- **A second iOS app used the exact name and was renamed.** App id 6499495337 by N V P Siva Priyatam was "Sudoku Sensei - Logic Puzzle" (its [privacy page](https://sudoku-sensei-privacy.netlify.app/) still links to `apps.apple.com/us/app/sudoku-sensei/id6499495337`), and it now shows as "Sudoku Arrow - Logic Puzzles" ([listing](https://apps.apple.com/us/app/sudoku-sensei-logic-puzzle/id6499495337)). Whether the bare name "Sudoku Sensei" is now unclaimed in App Store Connect is **unconfirmed**; only trying to create the app record will tell.
- **No US trademark for "SUDOKU SENSEI" turned up.** A Trademarkia search for the phrase returns only SUDOKU and SENSEI marks held separately ([Trademarkia search](https://www.trademarkia.com/search/trademarks?q=sudoku%20sensei)). The official USPTO search at [tmsearch.uspto.gov](https://tmsearch.uspto.gov/) is a JavaScript app and was not queried directly, so this is **unconfirmed** against the primary source.
- **The .com is taken; .app and .dev look free.** `sudokusensei.com` was registered in 2009 at GoDaddy and expires 2027-08-01 (whois); it serves a parking redirect to `/lander`. RDAP lookups for `sudokusensei.app` and `sudokusensei.dev` returned 404 ([rdap.org .app](https://rdap.org/domain/sudokusensei.app), [rdap.org .dev](https://rdap.org/domain/sudokusensei.dev)), which usually means unregistered. Confirm at a registrar before relying on it.
- **@sudokusensei on X exists but is suspended** (account id 3146661686, per the [fxtwitter API](https://api.fxtwitter.com/sudokusensei)). Suspended handles are not released, so treat it as unavailable.
- **The crowd is the bigger problem.** The "Sudoku that teaches" niche on iOS has filled up in 2026: Sudoku Coach: Trainer, doku.su: Sudoku Coach, Hintoku, Sudoku AI Coach & Learn, Sudoku Tutor (several), Sudoku Dojo (two), Sudoku Mentor, Sudoku Mentoring, Sudoku Explained, Toehold: Sudoku Explained, and Nine: Sudoku That Explains (see the table below). A name only differentiates if it is not another teacher noun.

**Is the exact name available on iOS?** Apple allows an app name once per localization across all developers, and a name held by someone else can only be reclaimed through a trademark claim ([Apple: Add a new app](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app/)). "Sudoku Sensei: Learn & Master" is a different string from "Sudoku Sensei", so the bare name may be accepted. Two caveats: the old id6499495337 record may still hold "Sudoku Sensei" in some localization, and shipping a near-identical name for a near-identical teaching app invites rejection under App Review Guideline 4.1 (copycats) and user confusion. Close variants such as "Sudoku Sensei: Learn to Solve" are probably accepted mechanically but sit right next to an app with the same pitch.

## Gotchas

- The iTunes Search API is fuzzy and capped, so "no hit" means "not in the top results", not "free".
- App Store name availability is only certain once App Store Connect accepts the name when creating the app record. Reserve it early; Apple releases names held by records that never ship after a period, but that does not help with a live app.
- The renamed id6499495337 suggests names in this niche churn quickly. Another developer can claim a free name at any time.

## Recommendation

Do not rename to "Sudoku Sensei". The trademark and domain picture is fine (.app and .dev look free, no SUDOKU SENSEI mark found), but a live iOS app called "Sudoku Sensei: Learn & Master" launched ten days ago with nearly the same pitch, the X handle is gone, the .com is parked, and the name has a 15-year history on SourceForge and DSiWare. Shipping under it would put us beside a lookalike and risk a copycat rejection or a takedown dispute.

Pick a name that is not another teacher noun. Of the options checked, "Sudoku Apprentice" and "Stepwise Sudoku" are the strongest: no App Store title hits, open .com domains, and both still say "you will learn". Before committing, run the exact name through App Store Connect (create the app record to reserve it), the USPTO search, and a registrar.

## Decision (2026-10-10)

The app is renamed **Sudoclue**. Sean chose it over Ninelight, Glimmer, and Lantern for a shorter, more casual name that hints at the hints. The USPTO search ([tmsearch.uspto.gov](https://tmsearch.uspto.gov/)) was run directly for this round.
