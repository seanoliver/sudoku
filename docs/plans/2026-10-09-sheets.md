# Polish step 4: sheets

**Goal:** the [sheet design](2026-10-09-sheets-design.md): card sheets that rise over a shrinking game, drag to dismiss, an animated close on every path, a centered Restart alert, and two Settings fixes.

**Architecture:** keep the native `<dialog>` for focus, Escape, and screen readers. Opening plays a CSS animation keyed to `data-kind`, so switching from a sheet to the Restart alert replays it. Closing adds `closing`, plays the exit animation, and calls `close()` on `animationend`; `cancel` (Escape) is intercepted the first time only. The game behind shrinks through `body:has(.sheet[open]:not(.closing):not([data-kind='restart'])) .app`. Dragging is pointer events on the handle strip, writing the dialog's `translate`; release decides close or snap back. CSS easing rather than Motion keeps the first load unchanged.

**Out of scope:** How to play's illustrated rows (needs directions), Install's content.
