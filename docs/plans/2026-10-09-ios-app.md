# R9 step 5: iOS app parity

**Goal:** ship the Capacitor wrapper proven in the device spike from the same codebase as the website, with the haptics setting and privacy page from the [design](2026-10-09-ios-app-design.md).

**Architecture:** `BUILD_TARGET=ios` turns on `output: 'export'` and exposes `NEXT_PUBLIC_BUILD_TARGET`, which removes the service worker, analytics, the install card, and the haptics and swipe code from the website's bundle. `pnpm build` is unchanged; `pnpm build:ios` exports and syncs into `ios/`. Native code is a `CAPBridgeViewController` subclass (set in `SceneDelegate`, since Capacitor 8's template ignores the storyboard's class) that adds a left-edge pan gesture and streams it to `window.sudokuSwipe`.

## Tasks

1. Build split: `next.config.ts`, `manifest.ts` `force-static`, `capacitor.config.ts`, the `build:ios` script, `ios/`, lint ignores for `out/` and `ios/`.
2. Native guards: service worker, analytics, install card.
3. Haptics: `src/lib/haptics.ts`, cues at selection, entry, unit, solve, and refusal, gated by a `haptics` preference (default on).
4. Swipe back: `src/lib/native-back.ts`, the live Home and Learn underlays, the game copy taken on leaving for a lesson or replay, and `MainViewController`.
5. Settings and privacy: grouped Haptics and About rows, the privacy sheet, `/privacy`.
6. Tests: preferences (haptics default and parse), Settings rows and the privacy sheet, the `/privacy` page, no Haptics switch on the website. The native swipe and haptics are checked on device.
7. Docs: AGENTS.md iOS build notes, roadmap status.
