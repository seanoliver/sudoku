# September 21, 2026 playtest

Recorded: September 22, 2026.

This record preserves Sean's September 21 playtest notes. Feature requests and research spikes are tracked in the [roadmap](../ROADMAP.md). Research outcomes remain uncommitted until their scope is reviewed.

## Original notes

### Feature Ideas

- Focus on number mode is the default when selecting a number
- You can select a number by tapping a number from the number row
- When an empty square is selected the impossible numbers are disabled (configurable)
- Entering an incorrect number gives you more obvious feedback that you got it wrong
- Red faded background color for crossed out cells that would otherwise be green with smart highlighting but the given number is crossed out
- Option to autofill a cell when there’s only one candidate possible (and its noted in the cell)

### Things to Think Through

- Something is wrong with the populate all cell notes algorithm. It’s leaving entire squares empty.
- We need a level even harder than hard
- It’s still not easy enough to switch between note and exclude mode
- Less messy way of showing how many numbers are left for a given number in the number row
- Consider the good sudoku style number row
- Earn points for the level of difficulty in the deductions you make
- Some way to comparison highlight numbers to more easily see where they overlap
- OR ability to highlight only cells where the same numbers appear? Is that a thing?
- Need a unique way to store celebrate and share big wins / accomplishments
  - How to make really nice IG native stories about particularly good wins?

## September 22 clarification

- Number-row taps enter a value only when an empty cell is selected. With a filled cell or no cell selected, they focus the tapped digit. Selecting a different digit while a filled cell is selected does not replace its value.

- Additional request: Light and Dark modes with system appearance detection. The existing Settings controls already provide Light, Dark, and System; the roadmap now records that behavior explicitly as shipped.
